# WinAI (openrecall-npu)

Локальные аналоги ИИ-функций Windows Copilot+ PC, которые работают сами по себе,
есть они в вашей Windows или нет. Рассчитано на ноутбуки Intel Core Ultra (NPU + iGPU Arc),
например Core Ultra 5 226V. Всё считается и хранится на этом компьютере.

| Функция Windows | Здесь | Где считается |
|---|---|---|
| Recall | запись экрана, OCR, поиск по смыслу с картинками | эмбеддинги на NPU |
| Click to Do | Ctrl+Alt+Q → выделить область → копировать, объяснить, кратко, перевести, ответить | OCR + LLM |
| Live Captions с переводом | субтитры поверх окон к звуку компьютера или микрофону, перевод на русский | Whisper на NPU |
| Studio Effects | размытие/замена фона и автокадрирование, виртуальная камера для Zoom/Telegram/Discord | MediaPipe (CPU, лёгкая) |
| Семантический поиск | поиск по смыслу в txt, md, код, pdf, docx, pptx, xlsx и тексте на картинках | эмбеддинги на NPU |
| Супер-разрешение (Photos) | увеличение фото ×4 | NPU/GPU |
| Generative erase | закрасил кистью → объект исчез (LaMa) | NPU/GPU |
| Cocreator (Paint) | картинка по описанию и наброску (LCM Dreamshaper) | GPU |
| Phi Silica | локальная LLM: чат и все текстовые действия выше | общий движок или своя |

## Установка

Скачайте `WinAI-Setup-x.y.z.exe` со страницы [Releases](https://github.com/GANTERMIST/openrecall-npu/releases)
и запустите. Права администратора не нужны, Python ставить не надо.
Нужен только свежий драйвер NPU/GPU от Intel.

Установщик кладёт программу в `%LOCALAPPDATA%\Programs\WinAI`, делает ярлыки
(по желанию — автозапуск при входе в Windows) и запускает `WinAI.exe`. При первом запуске
`WinAI.exe` сам скачивает Python 3.12 и зависимости (5–15 минут, ~2 ГБ) и показывает ход
установки. Потом появляется значок в трее и панель http://127.0.0.1:8765.
Модели скачиваются при первом использовании функции или сразу, если отметить это в установщике.

Есть и портативный архив `WinAI-portable-x.y.z.zip`: распакуйте куда угодно и запустите `WinAI.exe`.

`WinAI.exe --setup` переустанавливает зависимости, `WinAI.exe --models` скачивает все модели.
После обновления программы зависимости доустанавливаются сами.

Для разработки без установщика: Python 3.12 и `start.bat`.

## Запуск В панели включаются службы (Recall, Click to Do,
субтитры, камера); включённые запустятся сами при следующем старте.

Проверить, что работает на этом компьютере:
```
.venv\Scripts\python -m winai doctor
```

Всё доступно и из консоли: `python -m winai help`.

## Питание и память

- **Режим** `auto`: от сети — «производительность», от батареи — «экономия». Можно зафиксировать
  в `config.toml` (`power_mode = "eco"`).
- Постоянные лёгкие задачи (эмбеддинги, Whisper) всегда идут на **NPU**, iGPU остаётся свободной.
- LLM: от сети на GPU, от батареи сначала NPU. Картинки — GPU.
- Если устройство не справилось с моделью, автоматически берётся следующее (NPU → GPU → CPU).
  Порядок можно задать вручную: `set WINAI_DEVICE_LLM=GPU,CPU`.
- Recall от батареи пишет вдвое реже, ниже 20% заряда ставится на паузу. Камера от батареи — 15 кадров/с.
- Модели, которые не использовались 10 минут, выгружаются из памяти (ОЗУ общая с iGPU).
  Скомпилированные модели кэшируются в `models/cache`, так что NPU долго компилирует только первый раз.

## Общий движок

Текст (чат, Click to Do, перевод) и распознавание речи сначала идут в общий сервер
`npu-llm-hub` (http://127.0.0.1:8100/v1, OpenAI-совместимый), чтобы модели не грузились дважды.
Если он не запущен, WinAI поднимает свою модель через OpenVINO GenAI
(`Phi-3.5-mini-instruct-int4`, `whisper-small`). Отключить это: `llm_fallback = "off"`.
Эмбеддинги для поиска всегда свои (`multilingual-e5-small`), чтобы индекс не зависел от сервера.

## Что скачивается

При первом использовании функции, в папку `models/`:
e5-small (экспорт через optimum), Phi-3.5-mini int4 (~2.3 ГБ), whisper-small,
LCM Dreamshaper int8 (~1 ГБ), LaMa (~200 МБ), OMZ single-image-super-resolution-1032.
Если модель апскейла или удаления не скачалась, работает простой метод OpenCV, чтобы функция не пропадала.

## Особенности

- **Studio Effects**: для виртуальной камеры установите [OBS Studio](https://obsproject.com/)
  (нужен только её драйвер, саму OBS запускать не надо). В звонке выберите камеру «OBS Virtual Camera».
- **Click to Do**: горячая клавиша меняется в `config.toml` (`hotkey_clicktodo`).
- **Recall**: окна с «пароль», «банк», «incognito» и т. п. в заголовке не записываются (`BLOCKLIST`
  в `winai/recall.py`). Скриншоты могут содержать личные данные, храните `data/` в безопасности.
  Старые записи: `python -m winai recall purge --days 30`.
- Старые команды `python recall.py capture|search|serve` продолжают работать.

## Сборка exe и установщика

GitHub Actions (`.github/workflows/build.yml`) на каждый пуш собирает `WinAI.exe` (PyInstaller,
`launcher.py`), установщик (Inno Setup, `installer/winai.iss`) и портативный архив — их можно
скачать в артефактах сборки. Тег `v1.0.0` публикует их в Releases:
```
git tag v1.0.0 && git push origin v1.0.0
```

## Тесты

```
pip install pytest
python -m pytest tests
```
Тесты проверяют логику без NPU и моделей: выбор устройств по питанию, откат устройств,
поиск, нарезку речи на фразы, клиент движка, склейку плиток апскейла, кадрирование камеры.
